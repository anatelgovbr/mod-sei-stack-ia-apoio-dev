# Arquitetura

Esta pasta reúne a documentação de arquitetura do projeto. Cada tipo de documento tem uma subpasta própria, com um `README.md` que explica como ela funciona.

| Caminho | Conteúdo |
|---|---|
| [`adr/`](adr/README.md) | Decisões arquiteturais registradas como ADR (Architecture Decision Record), em subpastas por módulo e em `sei/` para o SEI inteiro, com as regras de registro |
| [`ADR-TEMPLATE.md`](ADR-TEMPLATE.md) | Modelo para escrever uma ADR nova |

Outros tipos de documento de arquitetura, como diagramas do modelo C4, entram como subpastas novas, cada uma com o seu `README.md`. Ao criar uma subpasta, acrescente uma linha na tabela acima.
