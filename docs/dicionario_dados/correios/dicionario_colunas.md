## md_cor_adm_integr_tokens

Representa a credencial de autenticação de uma funcionalidade de integração com a API dos Correios para um contrato específico do órgão, com uma linha para cada combinação entre funcionalidade de integração e contrato. O registro é criado ou passa a integrar o conjunto quando o administrador cadastra a autenticação de uma funcionalidade para um contrato na tela de Mapeamento das Integrações, ou quando o módulo insere automaticamente um registro vazio ao buscar pela primeira vez a integração de uma funcionalidade ainda não configurada para o contrato. Inclui apenas as combinações de funcionalidade e contrato já solicitadas ou cadastradas e exclui combinações nunca utilizadas. Mantém o estado atual da credencial e do token de autenticação por contrato, referente ao contrato vigente no momento da consulta. É produzido a partir do cadastro administrativo na tela de Mapeamento das Integrações e da renovação automática de token pela API REST dos Correios, e é utilizado pelas chamadas do módulo às APIs dos Correios para autenticar as operações realizadas em nome de cada contrato. Não deve ser interpretado como o cadastro geral da funcionalidade de integração nem como histórico de tokens anteriores, pois mantém apenas a credencial vigente.

| Tabela | Coluna | Descrição |
|---|---|---|
| md_cor_adm_integr_tokens | id_md_cor_adm_integr_tokens | Identificador do registro de credencial de autenticação de uma funcionalidade de integração para um contrato, correspondente ao número sequencial atribuído no cadastro da credencial, determinado no momento do cadastro. É expresso em número inteiro sequencial e obtido por geração automática do banco de dados. Não se aplica, pois a coluna não permite valor nulo. É utilizado para identificar univocamente o registro nas operações de consulta, alteração e exclusão e não representa a funcionalidade de integração nem o contrato isoladamente. |
| md_cor_adm_integr_tokens | data_exp_token | Data/hora de expiração do token de autenticação da funcionalidade de integração para o contrato, correspondente ao instante em que o token deixa de ser válido para uso nas chamadas à API dos Correios, determinado pela resposta da operação de geração de token da API dos Correios. É expresso em data e hora e obtido automaticamente a partir do retorno da chamada à API de geração de token. O valor nulo significa que ainda não foi gerado nenhum token para esta credencial. É utilizado para decidir se um novo token deve ser solicitado antes de uma nova chamada à API e não representa a data em que a credencial foi cadastrada. |
| md_cor_adm_integr_tokens | id_md_cor_adm_integracao | Identificador da funcionalidade de integração com a API dos Correios à qual a credencial pertence, correspondente à funcionalidade mapeada no módulo (por exemplo, Gerar Token, Rastrear Objeto, Consultar CEP), determinado no cadastro da credencial. É expresso em referência à funcionalidade de integração cadastrada e obtido pela funcionalidade selecionada na tela de Mapeamento das Integrações no momento da inclusão da credencial. Não se aplica, pois a coluna não permite valor nulo. É utilizado para relacionar a credencial à funcionalidade de integração correspondente e não representa o contrato ao qual a credencial se aplica. |
| md_cor_adm_integr_tokens | id_md_cor_contrato | Identificador do contrato do órgão com os Correios ao qual a credencial de autenticação pertence, correspondente ao contrato selecionado no cadastro da credencial, determinado no momento do cadastro ou da primeira busca automática da integração para o contrato. É expresso em referência ao contrato cadastrado no módulo e obtido pela seleção do contrato na tela de Mapeamento das Integrações. Não se aplica, pois a coluna não permite valor nulo. É utilizado para segmentar a credencial de autenticação por contrato e não representa a funcionalidade de integração à qual a credencial se aplica. |
| md_cor_adm_integr_tokens | senha | Senha de autenticação do usuário do órgão utilizada na funcionalidade de integração com a API dos Correios, correspondente à credencial informada pelos Correios para o contrato, determinada no cadastro da credencial. É expresso em texto cifrado e obtido por digitação do administrador na tela de Mapeamento das Integrações. O valor nulo significa que nenhuma senha foi cadastrada para esta credencial. É utilizado para autenticar as chamadas do módulo à API dos Correios e não representa o usuário nem o token de autenticação. |
| md_cor_adm_integr_tokens | sin_ativo | Situação da credencial de autenticação da funcionalidade de integração para o contrato, correspondente a se a credencial está disponível para uso pelas chamadas à API dos Correios, determinada pelo cadastro ou pela desativação administrativa da credencial. É expresso em um domínio fechado de 2 valores fixos, listados a seguir, e obtido por ação do administrador ou pelo cadastro automático da credencial. Não se aplica, pois a coluna não permite valor nulo. É utilizado para controlar se a credencial deve ser considerada nas chamadas de integração e não representa a validade do token armazenado. Representa status categórico:<ul><li>S: Ativo</li><li>N: Não ativo</li></ul> |
| md_cor_adm_integr_tokens | token | Token de autenticação retornado pela API dos Correios para a funcionalidade de integração e o contrato, correspondente à credencial temporária usada nas chamadas subsequentes à API, determinado pela resposta da operação de geração de token. É expresso em texto e obtido automaticamente a partir do retorno da chamada à API de geração de token dos Correios, ou informado manualmente como token inicial no cadastro da credencial. O valor nulo significa que ainda não foi gerado ou informado nenhum token para esta credencial. É utilizado para autenticar as chamadas subsequentes à API dos Correios e não representa a senha nem o usuário de autenticação. |
| md_cor_adm_integr_tokens | usuario | Usuário do órgão cadastrado no Fale Conosco dos Correios utilizado na funcionalidade de integração para o contrato, correspondente à identificação informada pelos Correios para o contrato, determinada no cadastro da credencial. É expresso em texto e obtido por digitação do administrador na tela de Mapeamento das Integrações. O valor nulo significa que nenhum usuário foi cadastrado para esta credencial. É utilizado para autenticar as chamadas do módulo à API dos Correios e não representa a senha nem o token de autenticação. |

## md_cor_adm_integracao

Representa a configuração de uma funcionalidade da API dos Correios integrada ao módulo, com uma linha para cada funcionalidade oficial suportada. O registro é criado quando o módulo é instalado, populando as dez funcionalidades oficiais previstas (Gerar Token, Rastrear Objeto, Consultar CEP, Serviços Postais, Solicitar Etiquetas, Pré Postagem Nacional, Emitir Rótulo, Download Rótulo, Aviso de Recebimento e Cancelar Pré Postagem), ou quando o administrador mapeia manualmente uma dessas funcionalidades ainda não cadastrada na tela de Mapeamento das Integrações. Inclui somente as funcionalidades oficiais previstas pelo módulo e exclui qualquer outra operação da API dos Correios não mapeada. Mantém a configuração atual do endpoint, da credencial padrão e da situação de cada funcionalidade, referente à configuração vigente no momento da consulta. É produzido pela instalação do módulo e pela manutenção administrativa na tela de Mapeamento das Integrações, e é utilizado pelas chamadas do módulo à API REST dos Correios para localizar o endpoint e a credencial de cada operação, servindo de base para as credenciais específicas por contrato. Não deve ser interpretado como o cadastro de credenciais específicas de cada contrato, que fica em registro à parte por funcionalidade e contrato.

| Tabela | Coluna | Descrição |
|---|---|---|
| md_cor_adm_integracao | id_md_cor_adm_integracao | Identificador da configuração de integração de uma funcionalidade da API dos Correios, correspondente ao número sequencial atribuído no cadastro do mapeamento, determinado no momento do cadastro. É expresso em número inteiro sequencial e obtido por geração automática do banco de dados. Não se aplica, pois a coluna não permite valor nulo. É utilizado para identificar univocamente o registro nas operações de consulta, alteração e exclusão e não representa o código numérico da funcionalidade, armazenado em coluna própria. |
| md_cor_adm_integracao | data_exp_token | Data/hora de expiração do token de autenticação padrão da funcionalidade de integração, correspondente ao instante em que esse token deixa de ser válido, determinado pela resposta da operação de geração de token da API dos Correios. É expresso em data e hora e obtido automaticamente a partir do retorno da chamada à API de geração de token ou informado na instalação do módulo. O valor nulo significa que ainda não foi gerado nenhum token padrão para esta funcionalidade. É utilizado para decidir se um novo token padrão deve ser solicitado e não representa a data de expiração das credenciais específicas de cada contrato. |
| md_cor_adm_integracao | funcionalidade | Código da funcionalidade da API dos Correios mapeada pelo módulo, correspondente à operação oficial integrada, determinado na instalação do módulo ou na seleção do administrador ao cadastrar um novo mapeamento. É expresso em um domínio fechado de 10 valores fixos, listados a seguir, e obtido pela seleção do administrador entre as funcionalidades ainda não mapeadas. Não se aplica, pois a coluna não permite valor nulo. É utilizado para determinar qual operação da API dos Correios o registro configura e não representa o nome de exibição da funcionalidade, armazenado em coluna própria. Valores do domínio:<ul><li>1: Gerar Token</li><li>2: Rastrear Objeto</li><li>3: Consultar CEP</li><li>4: Serviços Postais</li><li>5: Solicitar Etiquetas</li><li>6: Pré Postagem Nacional</li><li>7: Emitir Rótulo</li><li>8: Download Rótulo</li><li>9: Aviso de Recebimento</li><li>10: Cancelar Pré Postagem</li></ul> |
| md_cor_adm_integracao | nome | Nome de exibição da funcionalidade de integração mapeada, correspondente à descrição textual da operação da API dos Correios, determinado na instalação do módulo ou pela seleção da funcionalidade no cadastro. É expresso em texto e obtido automaticamente a partir da funcionalidade selecionada, sem edição direta pelo administrador. Não se aplica, pois a coluna não permite valor nulo. É utilizado para identificar a funcionalidade nas telas de administração e não representa o código numérico da funcionalidade, armazenado em coluna própria. |
| md_cor_adm_integracao | senha | Senha de autenticação padrão utilizada na funcionalidade de integração com a API dos Correios, correspondente à credencial informada pelos Correios para a funcionalidade, determinada no cadastro do mapeamento. É expresso em texto cifrado e obtido por digitação do administrador na tela de Mapeamento das Integrações. O valor nulo significa que nenhuma senha padrão foi cadastrada para esta funcionalidade. É utilizado para autenticar as chamadas à API dos Correios quando não há credencial específica por contrato e não representa o usuário nem o token de autenticação. |
| md_cor_adm_integracao | sin_ativo | Situação da configuração de integração da funcionalidade da API dos Correios, correspondente a se a funcionalidade está disponível para uso pelo módulo, determinada pelo cadastro ou pela desativação administrativa. É expresso em um domínio fechado de 2 valores fixos, listados a seguir, e obtido por ação do administrador na tela de Mapeamento das Integrações. Não se aplica, pois a coluna não permite valor nulo. É utilizado para controlar se a funcionalidade deve ser considerada disponível para novas credenciais e chamadas de integração e não representa a validade do token armazenado. Representa status categórico:<ul><li>S: Ativo</li><li>N: Não ativo</li></ul> |
| md_cor_adm_integracao | token | Token de autenticação padrão retornado pela API dos Correios para a funcionalidade de integração, correspondente à credencial temporária usada nas chamadas à API quando não há credencial específica por contrato, determinado pela resposta da operação de geração de token. É expresso em texto e obtido automaticamente a partir do retorno da chamada à API de geração de token dos Correios. O valor nulo significa que ainda não foi gerado nenhum token padrão para esta funcionalidade. | md_cor_adm_integracao | url_operacao | Endereço do endpoint da API dos Correios correspondente à funcionalidade mapeada, correspondente à URL utilizada nas chamadas HTTP da operação, determinado no cadastro do mapeamento. É expresso em texto de URL e obtido por digitação do administrador na tela de Mapeamento das Integrações, inicialmente preenchido pela instalação do módulo com o endereço do ambiente de homologação dos Correios. Não se aplica, pois a coluna não permite valor nulo. É utilizado pelas chamadas do módulo à API dos Correios para localizar o endpoint da operação e não representa o ambiente de homologação ou produção de forma explícita em coluna própria. |
| md_cor_adm_integracao | usuario | Usuário do órgão cadastrado no Fale Conosco dos Correios utilizado como credencial padrão na funcionalidade de integração, correspondente à identificação informada pelos Correios, determinada no cadastro do mapeamento. É expresso em texto e obtido por digitação do administrador na tela de Mapeamento das Integrações. O valor nulo significa que nenhum usuário padrão foi cadastrado para esta funcionalidade. É utilizado para autenticar chamadas à API dos Correios quando não há credencial específica por contrato e não representa a senha nem o token de autenticação. |

## md_cor_adm_par_ar_infrigen

Representa um motivo de devolução de objeto postal configurável para o processamento de retorno de Aviso de Recebimento (AR), com uma linha para cada motivo cadastrado. O registro é criado quando o administrador do módulo cadastra um novo motivo na tela Parâmetros para Retorno da AR, seção Motivo de Objeto Devolvido. Inclui motivos ativos e inativos vinculados à parametrização de AR do módulo e exclui motivos usados por outras finalidades do SEI. Mantém o estado atual do cadastro, marcando por exclusão lógica os motivos que não podem ser fisicamente removidos por já estarem vinculados a um processamento de retorno de AR. É produzido a partir do cadastro administrativo do módulo e utilizado para classificar, no processamento de retorno de AR, o motivo pelo qual um objeto foi devolvido e para determinar se esse motivo configura infringência contratual sujeita a cobrança dos Correios. Não deve ser interpretado como o registro do próprio evento de devolução, que é mantido em md_cor_retorno_ar_doc.

| Tabela | Coluna | Descrição |
|---|---|---|
| md_cor_adm_par_ar_infrigen | id_md_cor_param_ar_infrigencia | Identificador do motivo de devolução configurado para o processamento de retorno de AR, correspondente ao registro único de cada motivo cadastrado, determinado na criação do registro. É expresso em número sequencial interno e obtido por geração automática do módulo no cadastro. Não se aplica, pois a coluna não permite valor nulo. É utilizado para referenciar o motivo em md_cor_retorno_ar_doc e não representa o motivo de infringência de outro módulo do SEI. |
| md_cor_adm_par_ar_infrigen | id_md_cor_parametro_ar | Identificador da configuração de parâmetros para retorno de AR à qual o motivo de devolução pertence, correspondente ao vínculo entre o motivo e a configuração única do módulo, determinado na criação do registro. É expresso em referência à configuração mantida em md_cor_adm_parametro_ar e obtido por atribuição automática à configuração única existente no cadastro. Não se aplica, pois a coluna não permite valor nulo. É utilizado para agrupar os motivos sob a configuração de parâmetros de AR do módulo e não representa vínculo com outro tipo de parametrização. |
| md_cor_adm_par_ar_infrigen | motivo_infrigencia | Descrição textual do motivo de devolução de um objeto postal pelos Correios, correspondente ao texto livre informado pelo administrador para identificar o motivo, determinado no cadastro do motivo. É expresso em texto de até 60 caracteres e obtido por digitação do administrador na tela Parâmetros para Retorno da AR. Não se aplica, pois a coluna não permite valor nulo. É utilizado para exibir e selecionar o motivo no processamento de retorno de AR e não representa a classificação de infringência contratual do motivo, registrada em coluna própria. |
| md_cor_adm_par_ar_infrigen | sin_ativo | Indicador de disponibilidade do motivo de devolução, correspondente a se o motivo está disponível para seleção no processamento de retorno de AR, determinado por ação administrativa de ativação ou desativação, inclusive desativação automática quando o motivo já está vinculado a um processamento existente e não pode ser removido. É expresso em um domínio fechado de 2 valores fixos, listados a seguir, e obtido por ação direta do administrador na tela Parâmetros para Retorno da AR. Não se aplica, pois a coluna não permite valor nulo. É utilizado para controlar a exibição do motivo na lista de seleção e não representa a classificação de infringência contratual do motivo. Representa status categórico:<ul><li>S: Ativo</li><li>N: Não ativo</li></ul> |
| md_cor_adm_par_ar_infrigen | sin_infrigencia | Indicador de infringência contratual do motivo de devolução, correspondente a se a devolução por esse motivo configura descumprimento do contrato pelos Correios sujeito a cobrança, determinado pela marcação do administrador ao cadastrar ou alterar o motivo. É expresso em um domínio fechado de 2 valores fixos, listados a seguir, e obtido pela marcação da opção Infringência Contratual na tela Parâmetros para Retorno da AR. Não se aplica, pois a coluna não permite valor nulo. É utilizado para orientar a geração de documento de cobrança quando um objeto é devolvido por esse motivo e não representa a disponibilidade do motivo para seleção. Representa status categórico:<ul><li>S: Configura infringência contratual</li><li>N: Não configura infringência contratual</li></ul> |

## md_cor_adm_parametro_ar

Representa a configuração de parâmetros para retorno de Aviso de Recebimento (AR) e geração de cobrança de AR pendente do módulo, com uma linha única contendo a configuração vigente do módulo. O registro é criado na primeira gravação dos parâmetros pelo administrador na tela Parâmetros para Retorno da AR e nunca é recriado, apenas alterado nas gravações seguintes, pois a tela sempre consulta e atualiza o único registro existente. Inclui os prazos, tipos de documento, tipo de conferência, regra de nível de acesso e modelo de cobrança usados pelo módulo e exclui os motivos de devolução individuais, mantidos em md_cor_adm_par_ar_infrigen. Mantém o estado atual da configuração, substituído a cada gravação, sem histórico de valores anteriores. É produzido pelo cadastro administrativo do módulo e utilizado pelo processamento de retorno de AR e pela geração de documentos de cobrança de AR pendente. Não deve ser interpretado como um histórico de configurações anteriores, já que somente a configuração vigente é mantida.

| Tabela | Coluna | Descrição |
|---|---|---|
| md_cor_adm_parametro_ar | dias_exp_ret_ar | Prazo, em dias, de limite para o retorno do Aviso de Recebimento (AR), correspondente à quantidade de dias após a qual o fluxo de acompanhamento do AR não retornado é finalizado automaticamente, determinado pela configuração do administrador do módulo. É expresso em número de dias, como texto de até 6 caracteres, e obtido por digitação do administrador no campo Prazo em Dias para Limite de Retorno do AR. O valor nulo significa que nenhum limite de finalização automática do fluxo foi configurado. É utilizado pelo agendamento automático do módulo para finalizar o fluxo de acompanhamento de ARs não retornados e não representa o prazo para considerar o AR em atraso, definido em nu_dias_retorno_ar. |
| md_cor_adm_parametro_ar | id_contato | Identificador do contato do SEI usado como destinatário padrão do documento de cobrança de AR pendente, correspondente ao contato configurado na seção Padrão de Documento de Cobrança, determinado pela configuração do administrador do módulo. É expresso em referência a um contato do SEI e obtido pela seleção do administrador no campo Destinatário dessa seção. O valor nulo significa que nenhum destinatário padrão foi configurado para o documento de cobrança. É utilizado para preencher o destinatário de cada documento de cobrança gerado e não representa o destinatário da correspondência original expedida pelos Correios. |
| md_cor_adm_parametro_ar | id_hipotese_legal_ar | Identificador da hipótese legal predefinida aplicada ao documento externo de retorno ou devolução de AR quando o nível de acesso predefinido é restrito ou sigiloso, correspondente à hipótese legal configurada na seção Regra de Nível de Acesso, determinado pela seleção do administrador quando o nível de acesso predefinido em nivel_acesso_ar exige hipótese legal. É expresso em referência ao domínio de hipóteses legais do SEI e obtido pela seleção do administrador no campo Hipótese Legal dessa seção. O valor nulo significa que a regra de nível de acesso usa o nível do documento principal ou que o nível predefinido é público, não exigindo hipótese legal. É utilizado para fundamentar legalmente a restrição de acesso do documento externo de retorno ou devolução de AR gerado com nível de acesso predefinido e não representa a hipótese legal do documento principal que originou a expedição. |
| md_cor_adm_parametro_ar | id_md_cor_parametro_ar | Identificador da configuração de parâmetros para retorno de AR do módulo, correspondente ao registro único de configuração existente, determinado na criação do registro. É expresso em número sequencial interno e obtido por geração automática do módulo na primeira gravação dos parâmetros. Não se aplica, pois a coluna não permite valor nulo. É utilizado para referenciar a configuração a partir de md_cor_adm_par_ar_infrigen e não representa a identificação de um motivo de devolução individual. |
| md_cor_adm_parametro_ar | id_procedimento_cobranca | Identificador do processo do SEI no qual os documentos de cobrança de AR pendente são gerados, correspondente ao processo configurado na seção Padrão de Documento de Cobrança, determinado pela configuração do administrador do módulo. É expresso em referência a um processo do SEI, geralmente o processo de acompanhamento da execução do contrato com os Correios, e obtido pela indicação do administrador no campo Processo de Cobrança dessa seção. O valor nulo significa que nenhum processo de cobrança foi configurado, impedindo a geração de documentos de cobrança. É utilizado para determinar em qual processo cada documento de cobrança de AR pendente é incluído e não representa o processo de origem da expedição cobrada. |
| md_cor_adm_parametro_ar | id_serie | Identificador do tipo de documento do SEI usado como padrão para o documento externo gerado quando um AR é retornado, correspondente ao tipo de documento configurado na seção Padrão para Documento Externo de Retorno de AR, determinado pela configuração do administrador do módulo. É expresso em referência a um tipo de documento do SEI e obtido pela seleção do administrador no campo Tipo de Documento dessa seção. ## md_cor_ar_cobranca

Representa um documento de cobrança emitido contra os Correios por pendência de retorno de Aviso de Recebimento (AR), com uma linha para cada documento de cobrança gerado para uma solicitação de expedição. O registro é criado quando o usuário aciona a geração de documento de cobrança na tela ARs Pendentes de Retorno para uma ou mais solicitações de expedição com AR não retornado dentro do prazo contratual. Inclui os documentos de cobrança gerados automaticamente pelo módulo e exclui os documentos de cobrança emitidos manualmente fora do fluxo do módulo. É produzido a partir da geração de documento de cobrança no processo de cobrança configurado em md_cor_adm_parametro_ar e utilizado para relacionar cada documento de cobrança gerado à solicitação de expedição correspondente.
