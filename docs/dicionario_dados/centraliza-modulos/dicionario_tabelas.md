# Dicionário de Dados do Módulo SEI Centraliza Módulos - v1.0.0

| Tabela | Descrição |
|---|---|
| md_central_mds_dist | Associa módulo mantido a instalação de órgão externo, com uma linha para cada combinação de módulo e instalação registrada. O registro é criado ou passa a integrar o conjunto quando o órgão externo envia a versão de um módulo mantido. Inclui combinações com módulo mantido e instalação cadastrados e exclui envios sem módulo reconhecido ou sem instalação identificada. Mantém a versão informada do módulo e a data e hora do último recebimento referente ao momento do envio. É produzido a partir dos dados enviados pela instalação externa e utilizado para acompanhar a distribuição dos módulos mantidos entre os órgãos. Não deve ser interpretado ou utilizado como histórico completo de todos os envios ou como confirmação de execução bem-sucedida do módulo no órgão. |
| md_central_mds_instal | Representa a instalação externa do Sistema Eletrônico de Informações cadastrada para integração com os módulos centralizados, com uma linha para cada instalação identificada. O registro é criado ou passa a integrar o conjunto quando a instalação solicita uma chave de acesso e atende aos dados obrigatórios e ao domínio autorizado. Inclui instalações ativas e desativadas, com dados de identificação, conexão e autenticação, e exclui solicitações sem dados obrigatórios ou cuja URL não esteja autorizada. Mantém o estado cadastral e a chave de acesso associada ao momento do cadastro ou da renovação. É produzido a partir dos dados informados pela instalação externa e utilizado para autenticar os serviços e relacionar a instalação aos módulos distribuídos. Não deve ser interpretado ou utilizado como histórico de chaves emitidas, porque o cadastro pode ser renovado. |
| md_central_mds_mantido | Representa o catálogo de módulos mantidos pela Anatel, com uma linha para cada módulo registrado para distribuição. O registro é criado ou passa a integrar o conjunto quando um módulo é incluído no catálogo de módulos mantidos. Inclui a identificação de apresentação, a identificação usada no intercâmbio, o repositório e o endereço do repositório dos módulos cadastrados e exclui módulos que não foram registrados no catálogo. Mantém o cadastro corrente do módulo e de seu repositório referente ao momento da manutenção cadastral. É produzido a partir do cadastro inicial e da manutenção administrativa dos módulos e utilizado para localizar módulos, associá-los às instalações e informar seus repositórios. Não deve ser interpretado ou utilizado como histórico de versões ou como registro das instalações que receberam cada versão. |
| md_central_mds_white_url | Representa a lista de domínios autorizados para instalações externas, com uma linha para cada domínio cadastrado. O registro é criado ou passa a integrar o conjunto quando um domínio é incluído na lista de autorização. Inclui domínios institucionais permitidos para solicitar chave de acesso e exclui domínios que não foram cadastrados ou que não correspondem a uma entrada autorizada. Mantém a configuração corrente dos domínios autorizados referente ao momento da consulta de autorização. É produzido a partir da carga inicial e da manutenção administrativa da lista e utilizado para decidir se a URL informada na solicitação de chave pode prosseguir. Não deve ser interpretado ou utilizado como cadastro de instalações ou como confirmação de que uma URL específica pertence a uma instalação registrada. |
