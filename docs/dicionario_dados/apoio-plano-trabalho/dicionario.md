## md_apt_etapa_pl_doc_modelo

Armazena associações entre itens de etapa de planos de trabalho e documentos modelo de editor interno, limitadas a uma associação por item.

| Coluna | Descrição |
|---|---|
| id_md_apt_etapa_pl_doc_modelo | Número ID que identifica a associação entre o item de etapa e o documento modelo. |
| id_documento | Número ID que identifica o documento modelo de editor interno associado ao item de etapa. |
| id_item_etapa | Número ID que identifica o item de etapa do plano de trabalho associado ao documento modelo. |
