# Registro de adaptadores

Mapeia os alvos reconhecidos por esta skill, neste repositório, para o adaptador correspondente, em qualquer família presente em `adapters/`. Consultado a partir de `references/contrato-de-adaptador.md`, conforme a forma descrita lá.

| Alvo | Arquivo | Família técnica |
|---|---|---|
| SEI | `adapters/sei/sei.md` | InfraPHP |
| SIP | `adapters/sei/sip.md` | InfraPHP |
| Julgar | `adapters/sei/julgar.md` | InfraPHP |
| Módulo customizado do SEI ou do SIP | `adapters/sei/modulos/padrao.md` | InfraPHP |
