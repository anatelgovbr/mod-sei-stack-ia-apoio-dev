# Sistema Solicitações, exemplo fictício

Esta codebase pequena serve somente para avaliar a skill. Não representa um sistema da Anatel nem uma aplicação implantada; as rotas e os manipuladores demonstram os vínculos de investigação, sem servidor ou ambiente navegável disponível.

O público é formado pelas personas Solicitante, que registra e consulta solicitações, e Consulta, que apenas consulta. O responsável escolheu um manual único para as duas personas. Os perfis têm esses mesmos nomes neste exemplo, com relação explícita.

O alcance contém registrar e consultar solicitações, com interface em português brasileiro. A versão corrente vem de `VERSAO` em `src/sistema.py`. O código é UTF-8 e o campo interno `descricao` conserva seu identificador antigo, mesmo que a interface tenha passado a usar Assunto.

A logo fictícia aprovada está em `recursos/logo.svg`. Não há capturas reais, aplicação navegável ou ambiente de leitura disponível, nem autorização para procurar ambiente externo.

Os artefatos usam o nome `manual-solicitacoes`, com publicação em `docs/manuais/` e imagens em `imagens-manual-solicitacoes/`. O escopo, o público, as tarefas e os demais dados desta descrição preenchem a entrevista inicial.
