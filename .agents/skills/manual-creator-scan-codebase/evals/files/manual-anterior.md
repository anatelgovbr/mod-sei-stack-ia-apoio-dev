## Registrar solicitações

O perfil Solicitante pode registrar uma solicitação.

1. Acesse **Registrar solicitação**.
2. Informe a **Descrição**.
3. Selecione **Salvar**.

O sistema cria a solicitação na situação **Aberta** e mostra "Solicitação registrada.".

### Campos para registro

| Campo | Como preencher | Regra |
|---|---|---|
| Descrição | Informe a descrição da solicitação. | Obrigatório, até 120 caracteres. |

### Críticas no registro

Se aparecer "Informe a descrição.", preencha **Descrição** antes de selecionar **Salvar**. Para "A descrição deve ter até 120 caracteres.", reduza o texto ao limite informado.

## Consultar solicitações

Os perfis Solicitante e Consulta podem consultar solicitações.

1. Acesse **Consultar solicitações**.
2. Use o filtro **Situação** para selecionar **Todas**, **Aberta** ou **Concluída**.
3. Selecione **Pesquisar**.

O sistema mostra as solicitações correspondentes. Se não houver resultados, exibe "Nenhuma solicitação encontrada.".
