# Manual de pedidos para usuário externo

Público: usuário externo, perfil Externo. Versão do código: 1.0.0.

## Sumário

- [Registrar pedido](#registrar-pedido)
- [Consultar pedidos](#consultar-pedidos)
- [Orientação complementar](#orientação-complementar)

## Registrar pedido

1. Acesse **Pedidos > Registrar pedido**.
2. Preencha **Assunto**, obrigatório e com até 120 caracteres.
3. Se necessário, preencha **Referência antiga**.
4. Selecione **Salvar**.

A ajuda de **Assunto** informa "Descreva o pedido em até 120 caracteres.". A ajuda de **Referência antiga** informa "Informe a referência, se houver.".

Se o assunto estiver vazio, o sistema mostra "Informe o assunto.". Acima do limite, mostra "O assunto deve ter até 120 caracteres.". Ao salvar, mostra "Pedido registrado.".

## Consultar pedidos

1. Acesse **Pedidos > Consultar pedidos**.
2. Informe **Número**.
3. Selecione **Pesquisar**.

## Orientação complementar

O gestor recomenda guardar o número do pedido para acompanhar contratos, sem restringir outras aplicações do módulo.

> "Norma fictícia: A Referência antiga do contrato deve ser preservada por 5 dias úteis, salvo autorização expressa do responsável."

No portal institucional, acesse **Serviços > Pedidos > Pesquisa pública**. O procedimento pertence a outro sistema.
